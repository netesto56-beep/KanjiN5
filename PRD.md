# PRD — Приложение для изучения кандзи N5

Версия документа: 1.0
Статус: черновик первой версии

---

## Название приложения

**Kanji N5** — простая цифровая колода флеш-карточек для изучения японских кандзи уровня JLPT N5.

---

## Идея и назначение

Небольшое веб-приложение для тренировки кандзи уровня N5. Пользователь
открывает карточки с кандзи, вспоминает значение и чтения, переворачивает
карточку для проверки и ставит одну из четырёх отметок знания.

Отметки влияют на частоту показа карточки: то, что даётся сложнее,
попадается чаще, а уже знакомое — реже. Прогресс сохраняется в браузере,
поэтому ничего не теряется при закрытии вкладки.

Это приложение для начинающих, которые хотят быстро и без лишних сложностей
повторять кандзи с телефона или компьютера.

---

## Целевая аудитория

- Начинающие изучающие японский язык.
- Люди, которые готовятся к экзамену JLPT N5.
- Взрослые самоучки и студенты, которым нужна простая тренировка кандзи.
- Пользователи, которые хотят быстро повторять кандзи в браузере с телефона
  или компьютера.

Это не приложение для продвинутых пользователей и не полноценная школа.
Первая версия — для тех, кто только начинает.

---

## Основные функции (5)

### 1. Просмотр карточки кандзи

Карточка имеет две стороны.

**Лицевая сторона** (видна первой):
- сам кандзи, показанный крупно;
- маленькая строчка-подсказка под кандзи, где он показан в контексте
  (например, слово, в котором кандзи встречается), чтобы помочь вспомнить.

**Обратная сторона** (после переворота):
- значение кандзи (перевод);
- кунное чтение;
- примеры японских слов с этим кандзи и переводом.

### 2. Переключение между карточками с учётом отметок

Пользователь нажимает «Следующая карточка», и приложение выбирает карточку
по простому правилу частоты:
- «не знаю» — показывается чаще всех;
- «трудно» — чуть реже;
- «легко» — ещё реже;
- «знаю» — лишь иногда, для поддержания тонуса.

Это не сложное расписание повторений по датам, а простая частота показа.
Если карточек с высоким приоритетом нет, показываются остальные.

### 3. Четыре отметки знания

На каждой карточке можно поставить одну из отметок:
- **Не знаю** — кандзи будет показываться чаще;
- **Трудно** — кандзи показывается чуть реже;
- **Легко** — кандзи показывается ещё реже;
- **Знаю** — кандзи показывается лишь иногда для поддержания тонуса.

Отметку можно менять в любой момент. Она не удаляет карточку навсегда,
а только меняет частоту её показа.

### 4. Сохранение прогресса

Отметки сохраняются в браузере пользователя. При закрытии вкладки прогресс
не теряется и восстанавливается при следующем открытии. Регистрация
и аккаунт не нужны.

### 5. Простой фильтр и сводка

Можно показывать «все карточки» или фильтровать по отметкам:
«Не знаю», «Трудно», «Легко», «Знаю».

Сверху видна простая сводка-счётчики, например:
«Не знаю: 20, Трудно: 15, Легко: 10, Знаю: 5».
Это помогает понять, на чём сосредоточиться.

## Основной пользовательский сценарий

1. Пользователь открывает веб-приложение.
2. Видит **лицевую сторону** карточки: кандзи и строчку-контекст под ним.
3. Мысленно вспоминает значение и чтения.
4. Нажимает «Показать ответ» — карточка переворачивается, видна обратная
   сторона (значение, кунное чтение, примеры слов).
5. Ставит одну из отметок: «Не знаю», «Трудно», «Легко» или «Знаю».
6. Нажимает «Следующая карточка».
7. Приложение выбирает следующую карточку с учётом отметок: «Не знаю»
   попадается чаще, «Знаю» — редко.
8. Прогресс сохраняется в браузере.
9. Позже пользователь возвращается, открывает фильтр «Не знаю» или «Трудно»
   и повторяет то, что даётся сложнее.

Главный сценарий очень короткий:
**открыл → посмотрел лицевую сторону → вспомнил → перевернул → поставил
отметку → перешёл к следующей → вернулся позже.**

## Описание данных

### Колода кандзи

Внутри приложения хранится готовый фиксированный список кандзи уровня N5
(стандартный набор, около 80–103 символов в зависимости от источника).

Для каждого кандзи хранится запись:

| Поле | Описание | Пример |
|---|---|---|
| Кандзи | сам символ | 卵 |
| Значение | перевод | яйцо |
| Кунное чтение | чтение строкой | tamago |
| Примеры слов | список слов с переводом, столько, сколько нужно | 卵 (tamago) — яйцо; 鶏卵 (keiran) — куриное яйцо; 卵焼き (tamagoyaki) — омлет |

**Про онное чтение:** оно не выводится отдельной строкой, а проявляется
только через примеры слов. Пользователь запоминает онное чтение в контексте
реальных слов. Поэтому количество примеров не фиксировано жёстко —
подбирается так, чтобы показать все чтения кандзи в распространённых словах.

Например, у кандзи 日 (день, солнце) или 人 (человек) чтений много,
и для них примеров будет больше, чтобы охватить все чтения в контексте.

### Отметки и прогресс

Для каждой карточки хранится текущая отметка пользователя
(Не знаю / Трудно / Легко / Знаю). По умолчанию карточка считается
не отмеченной (например, «Не знаю» или «без отметки»).

## Технические решения

### Общее устройство

Приложение — простое веб-приложение, работающее в браузере без сервера.
Оно состоит из четырёх частей:

| Часть | Что делает |
|---|---|
| **HTML** | Описывает структуру страницы: что и где показывать (карточка, кнопки). |
| **CSS** | Отвечает за внешний вид: цвет, шрифт, оформление карточки, переворот. |
| **JavaScript** | Логика: переключение карточек, выбор по весам, отметки, сохранение. |
| **Данные** | Сам список кандзи N5. |

### Выбор следующей карточки (взвешенный случайный выбор)

Каждой отметке присвоен вес:

| Отметка | Вес | Частота показа |
|---|---|---|
| Не знаю | 4 | чаще всех |
| Трудно | 3 | чуть реже |
| Легко | 2 | ещё реже |
| Знаю | 1 | редко, для тонуса |

При выборе следующей карточки приложение «крутит барабан»: чем выше вес
карточки, тем выше шанс, что она попадётся. Случайность сохраняется —
даже карточка «Знаю» иногда выпадает для поддержания тонуса.

Возможное будущее улучшение (не для первой версии): не показывать одну
и ту же карточку несколько раз подряд.

### Сохранение прогресса

Для хранения отметок используется встроенное хранилище браузера
(localStorage). Серверы, базы данных и аккаунты не нужны. Прогресс живёт
на устройстве пользователя.

### Интерфейс

Интерфейс на русском языке. Приложение нормально открывается в браузере
на телефоне и компьютере (адаптивная вёрстка).

## Границы проекта

### Что входит в первую версию

- Фиксированный набор кандзи уровня JLPT N5.
- Одна колода карточек с двумя сторонами.
- Просмотр карточки (кандзи + контекст на лицевой стороне; значение,
  кунное чтение и примеры слов на обратной).
- Четыре отметки знания с влиянием на частоту показа.
- Переключение между карточками по взвешенному случайному выбору.
- Сохранение прогресса в браузере (localStorage).
- Фильтр по отметкам и простая сводка-счётчики.
- Интерфейс на русском языке, адаптивный для телефона и компьютера.

### Что НЕ входит в первую версию (осознанно исключено)

- Добавление своих карточек пользователем.
- Несколько колод, темы, уроки, сложные категории.
- Регистрация и вход в аккаунт.
- Синхронизация между телефоном и компьютером.
- Аудио и озвучивание произношения.
- Тесты и квизы.
- Сложное интервальное повторение по датам (расписание повторений).
- Мобильное приложение (только веб-версия).
- Словарь и отдельная страница со всеми словами (примеры прямо на карточке).

Если коротко: первая версия — это **простая цифровая колода кандзи N5
с четырьмя отметками, которые влияют на частоту показа, и сохранением
прогресса в браузере**.
