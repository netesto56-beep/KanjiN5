# DESIGN.md — Kanji N5

## 1. Философия дизайна
Интерфейс строится на принципах **строгого монохромного минимализма** (брутализм/вайрфрейм), как на предоставленном референсе.
*   **Высокий контраст:** Только черный и белый цвета. Это снижает когнитивную нагрузку и помогает фокусироваться на сложных иероглифах.
*   **Один экран:** Весь функционал (сводка, фильтр, карточка, кнопки) располагается на одном экране без переключения вкладок.
*   **Геометрия:** Четкие линии, прямые углы со скруглением, отсутствие теней и градиентов.

## 2. Цветовая палитра
Используются строго два цвета. Никаких акцентных цветов (красного, зеленого) для кнопок оценок.

*   **Background (Фон страницы):** `#FFFFFF` (Белый)
*   **Text / Border (Текст и обводки):** `#000000` (Черный)
*   **Active Background (Активный фон):** `#000000` (Черный)
*   **Active Text (Текст на активном фоне):** `#FFFFFF` (Белый)

## 3. Типографика
*   **Основной шрифт:** Системный гротеск без засечек (`Inter`, `Roboto`, `Helvetica Neue`, `system-ui`, `sans-serif`).
*   **Шрифт для кандзи:** `Noto Sans JP` (или аналогичный с поддержкой японского).
*   **Размеры:**
    *   **Кандзи на лицевой стороне:** `96px` (крупно, по центру).
    *   **Значение (перевод):** `24px`, `font-weight: bold`.
    *   **Кунное чтение:** `18px`, `font-weight: normal`.
    *   **Примеры слов:** `16px` (слово + чтение + перевод).
    *   **Подсказка (контекст на лицевой стороне):** `16px`, `color: #000000`, `opacity: 0.7` (или серый `#666666`, если допустим один оттенок серого для второстепенного текста, но лучше использовать черный с меньшим начертанием).
    *   **Сводка и фильтры:** `14px`.
    *   **Кнопки:** `16px`, `font-weight: bold`, `text-transform: uppercase` (или просто заглавные буквы для четкости).

## 4. Сетка и отступы
*   **Базовый шаг:** 8px.
*   **Контейнер:** Максимальная ширина `600px`, выравнивание по центру (`margin: 0 auto`), внутренние отступы `24px`.
*   **Отступы между блоками:** `16px` или `24px`.
*   **Скругления (Border Radius):**
    *   Карточки и крупные контейнеры: `8px`.
    *   Кнопки и поля ввода: `4px`.

## 5. Компоненты интерфейса

### 5.1. Верхняя панель (Сводка и Фильтр)
Располагается над карточкой.
*   **Сводка:** Текст в формате «Не знаю: 20 | Трудно: 15 | Легко: 10 | Знаю: 5».
*   **Фильтр:** Ряд кнопок-тегов (или выпадающий список в стиле референса) со значениями: «Все», «Не знаю», «Трудно», «Легко», «Знаю».
    *   Неактивный тег: Белый фон, черная рамка `1px solid #000`, черный текст.
    *   Активный тег: Черный фон, белый текст.

### 5.2. Карточка (Flashcard)
*   **Контейнер:** `border: 2px solid #000000; border-radius: 8px; padding: 32px; min-height: 350px; display: flex; flex-direction: column; justify-content: center; align-items: center; background: #FFFFFF;`
*   **Лицевая сторона:**
    *   Кандзи (по центру, огромный).
    *   Подсказка (контекст): берется **первое слово из массива `examples`**. Выводится мелким шрифтом под кандзи.
*   **Обратная сторона:**
    *   Значение (перевод) — крупно.
    *   Кунное чтение — строкой ниже.
    *   Примеры слов: список. Каждый элемент содержит: `word` (иероглифы), `reading` (чтение) и `meaning` (перевод).
    *   *Важно:* Онное чтение отдельной строкой **не выводится**, оно показывается только в контексте примеров слов (согласно PRD).
*   **Анимация:** Плавный 3D-переворот (flip) при нажатии кнопки «Показать ответ».

### 5.3. Кнопки действий (Управление)
*   **Кнопка «Показать ответ» / «Следующая карточка»:**
    *   Широкая кнопка на всю ширину карточки (или контейнера).
    *   `border: 2px solid #000; background: #FFF; color: #000;`
    *   При наведении (Hover): инверсия цветов (фон `#000`, текст `#FFF`).
*   **Кнопки оценок (4 шт):** «Не знаю», «Трудно», «Легко», «Знаю».
    *   Появляются только после переворота карточки.
    *   Располагаются в ряд (сетка `grid-template-columns: repeat(4, 1fr); gap: 8px;`).
    *   Оформление как у сегментированного контрола: рамка `2px solid #000`, скругление `4px`.
    *   Выбранная (активная) оценка заливается черным цветом с белым текстом. Невыбранные — белые с черным текстом.

## 6. Запреты (Чего нельзя делать)
1.  **Никаких цветов**, кроме черного и белого. (Никаких красных/зеленых кнопок для «Не знаю»/«Знаю»).
2.  **Никаких теней** (`box-shadow`), градиентов, размытий и прозрачности (кроме легкого понижения непрозрачности для второстепенного текста, если это необходимо).
3.  **Не переносить лишние элементы** из референса: тумблеры (toggles), слайдеры, иконки GPS/Wi-Fi/Audio/Video, календарь, вкладки (Tabs).
4.  **Не использовать** сильные скругления (pill-shape). Максимум `8px`.
5.  **Не добавлять** кнопку сброса прогресса (в первой версии ее нет).
6.  **Не выводить** онное чтение отдельной строкой.
